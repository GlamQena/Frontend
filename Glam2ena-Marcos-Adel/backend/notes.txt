                          git
* merge to github main branch: 
 1- 'git checkout main' (switch to local branch main) 
 2- 'git merge [branch-name]' (merge with the local branch  work) 
 3- 'git push -u origin main' (push to the remote main branch)

* leave merge commit message in Vim editor:
 1-press 'i' to enable INSERT mode
 2- write the message at the first line in orange 
 3- press 'Esc' to exit the '--insert--' mode
 4- write ':wq' to "write" the message and "quit" the editor

                    zod validations
- .optional() method pass the undefined values, while .nullable() pass the null values
  ,but both can't handle the empty string coming from the front-end form so it must handled with preprocess function to return undefined 
- handle all non-value cases (null, undefined, "", "   ") to return only undefined for the database document to be clean 
  (undefined fields without default value will be ignored in creation and can be handled to unset for updatinng).
